# DSH Web Control 远程控制

在 DSH 中安装本插件后，插件会主动连接你自己的中继服务器；用浏览器打开中继页面即可：

- 看到当前在线的 DSH 实例；
- 按 DSH 工作区分组、可折叠的会话树；
- 新建会话从工作区右侧的「+」打开弹窗，确认后创建；
- 没有实际对话的空白会话不显示在会话列表里；
- 新建会话时可以选择权限（只读 / 工作区可写 / 完全权限）、模型和思考级别，当前会话也可以随时切换；
- 可以保存多个中继配置，但同一时间只连接「当前使用」的那一个；
- 在浏览器里处理工具确认、单选/多选提问和自定义回答；
- 发送消息、Markdown 格式回复、工具调用和思考过程按轮折叠、停止当前回合；
- 在模型支持时切换思考级别。

## 配置

打开 DSH 左侧的 **插件**，在「已安装插件」中点击 **DSH Web Control 远程控制**，页面下方就是「DSH Web Control 连接设置」：

| 字段 | 说明 |
|---|---|
| 启用远程控制 | 总开关；关闭后插件不连接任何中继 |
| 配置名称 | 仅用于区分，例如「本地调试」「云中继」 |
| 中继服务器 | 云服务器 IP 或域名，例如 `1.2.3.4` |
| 端口 | 默认 `7801` |
| 插件令牌 | 可选；与当前中继的令牌一致（`config.json` 的 `pluginToken` 或 `DSWC_PLUGIN_TOKEN`） |
| 当前使用 | 单选；同一时间只连接选中的一个中继 |
| 电脑名称 | 显示在中继页面上的名字；留空使用主机名；所有中继共用 |
| 默认目录（不选工作区时） | 只有在没有任何工作区、点击「新建默认对话」时生效；留空时跟随 DSH 工作区/最近会话；所有中继共用 |

填写后点 **保存并连接**，立即生效，不需要重启 DSH。

也可以在 DSH 对话里用快捷命令：

```text
/webctl 1.2.3.4:7801
/webctl use 云中继
/webctl status
/webctl cwd D:\Projects\demo
/webctl token <令牌>
/webctl off
```

两种方式写的是同一份配置：`$DSH_HOME/dsh-web-control.json`。可以保存多个中继配置，但插件同一时间只连接「当前使用」的那一个。

> 从旧的 XDControl 版本升级时，插件首次加载会自动把 `$DSH_HOME/xdcontrol.json` 迁移成新文件（旧文件保留不动）；快捷命令也从 `/xdcontrol` 改名为 `/webctl`。

## 安全

中继使用用户名/密码登录，通信未加密。请只在你信任的网络或 VPN 中使用，并在云服务器安全组中限制来源。
